== README

Ruby on Rails basic application to allow users to find each other for the purpose of practicing languages. Featured in IE Business School Career Newsletter with over 300 users across the world. Constantly adding new features, open to suggestions.

* Ruby 2.3, Rails 5.0, using Puma server locally, Redis in production

* Using Carrierwave, Mini_magick, Fog, File Validator, and Remotipart for uploading images and materials

* Using AWS for storing images and materials

* Heroku for hosting

* Braintree for payments

* Prototyping chatbot technology through chatbots.io and modified pandorabots_api gem

* Basic Linkedin integration

* Geocoder for location

* Recaptcha to protect against spam and abuse

* Delayed Job and Sendgrid for sending and tracking emails

* Opengraph Parser for displaying link images

* Searchkick for searching users

* Acts-as-taggable-on for tagging posts

* Jquery-textcomplete-rails for autocomplete

* Database using Sqlite3 for development and Postgres in production

* Security test results from Acunetix, Beyond Security, and Detectify show medium to low vulnerability

* Some issues when running on internet explorer

* Services (language learning, matching, networking, trustworthy interactions)
